# 阶段2任务文档：战斗结算页 + 压力页（v2）

> 状态：**开发中**（living document）
> 用途：把「提交战损组件页」与「压力页」的布局、字段、交互、数据缺口整理清楚，再开始实现。
> 规则来源：`warroom_rules.txt §12`（士气/压力）；`rules_cn.txt`（快速战斗，无压力内容）。

## 0. 术语约定

- **战斗**：一次战斗结算（陆战或海战）。
- **回合**：游戏的一整个回合，可能包含多次战斗。
- **X / Y / Z**：
  - X = 本次战斗之前的累计值（跨战斗保留、跨回合清空）。
  - Y = 本次战斗产生的变化值。
  - Z = 玩家手动点击单元格产生的调整值（左键 +1、右键 -1）。

## 1. 战斗结算页（提交战损组件页）

- 独立的**组件式页面**，进入结算阶段后显示；**不显示**现在的单位分配面板。
- 布局：**国家为行**；纵列如下：

| 列 | 内容 | 交互 |
| --- | --- | --- |
| 击杀分 | 当回合所有击杀单位总分，显示 `X+Y+Z` | Z 可点 ± |
| 本轮击杀分 | 即上面的 Y；会根据其他列动态折算成分数 | 只读 |
| 各兵种列（步兵/炮兵/…） | 损失单位，显示 `X+Y+Z` | Z 可点 ± |

- 各兵种列：X = 本次战斗之前的损失数量（跨回合清空）；Y = 本次战斗变化值；Z = 手动调整。
- 击杀分列：X = 不计入本轮（本场）的击杀分；Y = 本轮（本场）击杀分；Z = 手动调整。
- **「提交战损」按钮只在这个页面出现**。
- Z 值的变动要**单独存储**，方便回合结算时追溯。

## 2. 压力页（真正的独立页面）

- 布局：**国家为横轴（列）**，纵轴为以下行：

| 行 | 内容 | 交互 |
| --- | --- | --- |
| 1 | 国家名称 | 只读 |
| 2 | 压力阈值（每国不同；达到该阈值进入下一压力阶段） | 只读（待数据） |
| 3 | 总压力值（直接加总，不用 X+Y+Z） | 点击不改变值；显示当前第几压力阶段 + 对应效果 |
| 4 | 上一轮压力 | 只读 |
| 5 | 本回合新增压力 | 只读（来自战斗结算） |
| 6 | 击杀分压力（有折算） | 只读（待折算表） |
| 7 | 击杀分（本回合损失单位总览） | 点击不 ±；显示「单位名：分值×数量=总分」列表 |
| 8 | 争夺领地分 | 左键 +1、右键 -1；**允许负值** |
| 9 | 勋章 / 战略物资分 | 左键 +1、右键 -1 |

- **击杀分压力（6）与击杀分（7）**使用战斗结算提供的数据（击杀分 + 死亡单位）。
- 每次点击「提交战损」都要**记录并更新到压力页，并写入日志**。
- 击杀分**跨回合清空**。
- **总压力单元格**根据当前压力阶段显示不同颜色；点击显示「第几压力阶段 + 该阶段效果」。

## 5. 已确认数据与结论（v3）

- 术语：**击杀分统一改为「伤亡点数」**。
- 压力阈值：德 6、日 7、意 4、英 6、苏(ussr) 6、美 5、中 4。
- 单位伤亡点数系数：步兵2、炮兵2、装甲4、战斗机4、轰炸机6（普通/战略均6）、潜艇6、巡洋舰10、战列舰20、航母20。
- 伤亡点数→压力换算：0–18→0；19–34→1；35–50→2；51–68→3；69–88→4；89–108→5；109+→6。
- QA1：本轮=本场战斗。
- QA2：伤亡点数列与本轮伤亡点数列均只读，由各兵种列折算相加。
- QA3：总压力 = 上一轮压力 + 本回合新增压力；争夺领地分/勋章分计入本回合新增压力（不重复加）。
- QA4：争夺领地分/勋章分 1:1 直接计入；负值抵扣压力。
- QA5：提交后 Y+Z 并入 X；跨回合清空 X；Z 单独留痕（adjustmentLog）。
- QA6/QA7：勋章/战略物资分 = 勋章/民用物资（同一概念）。
- QA8：采用顶栏「战斗 / 压力」视图切换；压力数据独立 localStorage 持久化。
- QA9：总压力点击显示阶段号 + §12 效果文案。
- QA10：新回合时 previousRoundStress=总压力，本回合新增/争夺领地/勋章分/伤亡清空。
